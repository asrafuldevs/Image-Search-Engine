# Image Search Engine

A simple web app that lets users search for images using the Unsplash API.

## Features
- Search images by keyword
- Display image results in a responsive grid
- Open image source links in a new tab
- Load more results with the **Show More** button

## Tech Stack
- HTML
- CSS
- JavaScript
- Unsplash API
